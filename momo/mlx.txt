step0 ウィンドウを一つ開くだけのコード
　１）Mlx()のインスタンスを作る
　２）そのメソッドとしてmlx_関数を呼ぶ
　３）ウィンドウタイトルの"Maze"はバイト列で渡す。このパッケージは自動的にencode('utf-8')をしてくれるので、
　　　"Maze"だけでよい。
　４）mlx_loopはブロックしないと無限ループに入り、ウィンドウが閉じるまで戻ってこない
'''Python
import mlx

m = mlx.Mlx()
mlx_ptr = m.mlx_init()
win_ptr = m.mlx_new_window(mlx_ptr, 800, 600, "Maze")
'''

step1 画像バッファでの描画
mlx_new_image(self, mlx_ptr, width, height)
　戻り値: 画像オブジェクトのポインタを返す
　
mlx_get_data_addr(self, img_ptr)
　戻り値: data_view(mlx_new_imageで作った画像の生ピクセルデータ全体で一次元配列。
　　　　　　画像は二次元→一行ずつ横に並べて、縦に連結して一本の長い配列として保存)
　　　　　bpp(1ピクセル当たりのビット数。実行してみてprintで確認。)
　　　　　size_line(一行当たりのバイト数)
　　　　　endian(整数をバイト列に分解するときどちらの端から並べるのをこのシステムが期待しているかわかる。リトルとビッグ
　　　　　　リトルは値の小さい桁から並べる。ビッグは値の大きい桁から)
mlx_put_image_to_window(self, mlx_ptr, win_ptr, img_ptr, x, y)
　戻り値:作った画像をウィンドに一括で貼り付ける

<流れ>
# 1)Mlxをインスタンス化
m = mlx.Mlx()

# 2)mlx_initで初期化
mlx_ptr = m.mlx_init()

# 3)mlx_new_windowで指定したタイトルとサイズで画面を開く
win_ptr = m.mlx_new_window(mlx_ptr, 800, 600, "Maze")

# 4)mlx_new_imageで画像オブジェクトを作成
img_ptr = m.mlx_new_image(mlx_ptr, 800, 600)

# 5)画像の生ピクセルデータの先頭アドレスや様々な情報を返す
data_view, bpp, size_line, endian = m.mlx_get_data_addr(img_ptr)

# 6)この画像を、このウィンドウの、この位置に貼る」という関連付け
m.mlx_put_image_to_window(mlx_ptr, win_ptr, img_ptr, 0, 0)

step2 画面を閉じる　キー入力を拾う。

# 1)コールバック関数on_keyを定義
def on_key(keycode, param):
    print(keycode)
    if keycode == 65307:  # 一般的なLinux(X11)でのESCキーコード。実際に確認してから確定させる
        m.mlx_loop_exit(mlx_ptr)

# 2)-step1-6)の下にコールバック関数を登録するための関数を登録
# キーが押されたらon_keyという関数を呼ぶという予約
m.mlx_key_hook(win_ptr, on_key, None)

# 3)mlx_loop(mlx_ptr)が呼ばれる → 監視ループが始まる（ここでブロックする）
#   -何かキーが押されるたびに → 登録しておいたon_key(keycode, param)が呼ばれる
#   -on_keyの中のprint(keycode)が実行される → その数値がターミナルに表示される
#   -もしkeycode == 65307（ESC）なら → m.mlx_loop_exit(mlx_ptr)が呼ばれる
#   -mlx_loop_exitが呼ばれたことで、ようやくmlx_loopの監視ループが終了し、プログラムの制御が戻ってくる
m.mlx_loop(mlx_ptr)
